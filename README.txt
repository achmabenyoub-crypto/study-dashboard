# StudyFlow — Study Dashboard

## التشغيل
1. فك ضغط الملف.
2. افتح `index.html` في Chrome أو Edge أو Firefox.
3. لا تحتاج إلى تثبيت أي برنامج.

## الملفات
- index.html: هيكل الصفحة.
- style.css: التصميم والألوان والاستجابة للهاتف.
- script.js: المهام، المؤقت، الإحصائيات، الوضع الليلي والحفظ المحلي.

## ملاحظة
المشروع يحفظ البيانات باستخدام localStorage، لذلك تبقى المهام والإحصائيات عند إغلاق المتصفح على نفس الجهاز والمتصفح.
